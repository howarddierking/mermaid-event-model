Event Model DSL

A text DSL and zero-build SVG renderer for Event Modeling diagrams.

Actors and aggregates on swimlanes, a strict horizontal timeline, collapsible data sections, and vertical-slice bounding boxes — authored as plain text and rendered as a Mermaid external diagram type.
